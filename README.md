# Project Name

A modern React application built with Vite, featuring hot module replacement (HMR) and comprehensive ESLint configuration.

## Tech Stack

- **React 18** - UI Library
- **Vite** - Build Tool & Development Server
- **ESLint** - Code Quality & Linting
- **React Compiler** - Optimized performance

## Features

- Lightning-fast development with Vite HMR
- Modern React with hooks and functional components
- ESLint configured with best practices
- React Compiler enabled for performance optimization
- Minimal setup for quick project initialization

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
